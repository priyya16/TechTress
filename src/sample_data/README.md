# Sample / synthetic inputs

These files are **Sample / Synthetic Data** for the hackathon demo.

They are not FDA FAERS extracts and not a real regulatory dossier.

- `adverse_events.csv` — representative adverse-event rows with synthetic drug names (used by the in-app Sample button)
- `demo_video_adverse_events.csv` — same AE file; use this when recording the **Upload CSV** step
- `dossier_outline.txt` — partial representative CTD outline with intentional gaps
- `demo_video_dossier.csv` — same outline as CSV; use this when recording the **Upload or paste** step
